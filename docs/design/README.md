# Design

| Path | What |
|---|---|
| `system/README.md` | The design system: colour, type, space, layout, charts, voice. Read before any UI work. |
| `system/tokens.json` | Every token value, dark and light. Mirrors `src/app/globals.css`. |
| `HANDOFF.md` | Build spec for the upcoming screens: data, queries, layout, tests, decisions to make. |
| `mockups/*.html` | Static mockups of those screens with sample data. Open in a browser; add `?theme=light` for the light theme. |

The same material lives as two private claude.ai artifacts: the "tradeSence" Design
System and the "tradeSence upcoming screens" Design canvas. These files are the copy the
code works from; if the artifacts change, refresh this folder.
